# CourtFit case-study media

Drop the recordings here with these exact filenames. Each feature section on
`courtfit.html` shows a labeled placeholder until the matching file exists, then
`courtfit.js` auto-reveals the video (no markup changes needed).

| File | Flow to record |
|------|----------------|
| `add-property.mp4` | **Add a property** — on a LoopNet listing, click the bookmarklet → it opens CourtFit and auto-extracts → the new property appears rated. |
| `property-details.mp4` | **The verdict** — open a property; scroll the rating, NOI/payback, court fit, demographics, condition & code, competition/whitespace, startup cost. |
| `map.mp4` | **The map** — toggle My sites / Competitors, change the Sport / Location / Courts filters, click a pin for its popup, then switch on the Demand heatmap. |
| `compare.mp4` | **Compare** — open the Compare tab, drag the weighting sliders, watch the leaderboard re-rank. |

## Tips
- Record at 16:10-ish (the slot is a wide desktop frame); 1280–1600px wide is plenty.
- Keep each clip short (~10–25s) and trimmed to the action.
- MP4 (H.264) plays inline everywhere; keep files reasonably small for the web.
- Optional: a `poster-*.jpg` first-frame isn't required — the placeholder covers the gap until the mp4 loads.
